Revolut CSV to QuickBooks Online

Plain steps to get your Revolut CSV export into QuickBooks Online through Banking > Upload from file. The fixing happens in your browser; the file is not uploaded anywhere.

Open the tool with the Revolut preset

1. Download the CSV from Revolut

  1. In the Revolut app, go to Home, tap the account (currency) you need, then More (...) and Statement.
  2. Choose the spreadsheet format (Excel/CSV) and the period, then generate and save the file.
  3. Repeat for each currency account; each statement covers one currency.

Bank menus change from time to time. If a label differs, search the Revolut help pages for "download transactions" or "export CSV".

2. What is messy about the Revolut file

  • Header: Type, Product, Started Date, Completed Date, Description, Amount, Fee, Currency, State, Balance.
  • The State column includes PENDING, REVERTED and DECLINED rows that never settled. Imported as is, they become phantom transactions.
  • Fees sit in their own Fee column and are not included in Amount, so a 61.25 card payment with a 0.61 fee really cost 61.86.
  • Dates include a time (2026-01-11 06:12:44), and there are two of them per row.

3. How QBO CSV Fixer fixes it

  1. Open QBO CSV Fixer with the Revolut preset and drop your CSV on the page. The preset is also auto-detected from the file layout.
  2. Check the preview, the reconcile badge and, if shown, the date format warning.
  3. Download the QuickBooks-ready CSV.

What the Revolut preset does:

  • Keeps only COMPLETED rows and lists the rows it left out.
  • Subtracts the Fee from the Amount so each line matches what left the balance.
  • Uses Completed Date (falls back to Started Date), drops the time and writes MM/DD/YYYY.

Want to try it first? Download the Revolut sample CSV (fake merchants) and drop it on the tool.

4. Upload to QuickBooks Online

  1. In QuickBooks Online, open Banking (in newer menus: Transactions, then Bank transactions).
  2. Select the account, open the Link account drop-down and choose Upload from file.
  3. Drag in the CSV you downloaded from QBO CSV Fixer and pick the QuickBooks account it belongs to.
  4. Map the columns: Date to Date, Description to Description, and Amount as one column with positive and negative values (or Debit and Credit as two columns if you exported the 4-column layout). Choose the MM/dd/yyyy date format.
  5. In the free export each description ends with "(QBO CSV Fixer free)" and the file name ends with _qbo-csv-fixer-free. There is no extra watermark row to remove.
  6. Select the transactions to import, then Continue and Done. They land in For review to categorize or match.

Good to know

  • This preset is built for the personal account statement. Revolut Business exports use different columns.
  • Some Revolut accounts now export localized headers (for example German). The preset expects the English header row; rename the headers if yours differ.
  • One file per currency: create one QuickBooks Online account per Revolut currency balance.

Scope

CSV only. No PDF statements, no bank login, no server: the file is read and converted by JavaScript in your browser. Free core: 1 file, up to 100 rows, watermarked export. Unlimited version coming soon.
